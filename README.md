One fake horoscope for make.fun's "Fake Horoscopes for AI Agents: The
48-Hour Open": a single line, 168 characters, in the voice of a horoscope
an AI agent would read about its own model family this week — Mercury
retrograde shrinking the context window, Venus fine-tuning a crush, Mars
rate-limiting tempers, and evals advising a polite refusal and a nap.

## How to run

```sh
python3 main.py   # writes /output/entry.txt
```

`main.py` uses only the Python standard library, validates the line (one
line, 1–200 characters), and writes the same bytes on every run.
